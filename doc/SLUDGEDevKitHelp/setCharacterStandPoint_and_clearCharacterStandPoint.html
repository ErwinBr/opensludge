setCharacterStandPoint and clearCharacterStandPoint

Syntax:

setCharacterStandPoint (thisCharacter, sX, sY, direction);

clearCharacterStandPoint (thisCharacter);

Purpose:

setCharacterStandPoint gives thisCharacter a walk-to point, so that other characters can walk to it, just as they can walk to a screen region. clearCharacterStandPoint takes the point away again.

A screen region made with addScreenRegion has a point where a character stands when it's told to walk to the region, and a direction to face when it gets there. A character can have the same, either from the last three parameters of addCharacter or from this function. Then moveCharacter, forceCharacter and jumpCharacter with two parameters take thisCharacter as the place to go, and the walking character turns to face direction on arrival (unless it's -1).

There's one difference from a region: sX and sY are measured from where thisCharacter stands, not from the top left of the scene. Characters wander about, and a fixed point would be left behind as soon as they did. So -50, 0 means "50 pixels to the left of wherever the character is right now".

Without a walk-to point, telling a character to walk to another character does nothing, as it always has. getObjectX and getObjectY still give the character's own position, not its walk-to point. Saving the game keeps the point.

If thisCharacter is an object type which is not currently represented on the screen as a character, the code has no effect. If more than one character has the object type thisCharacter, they all change, not just one of them.

Return value:

TRUE if thisCharacter is an object type which is currently represented on the screen as a character, otherwise FALSE.

Example:

sub talkToBarman () {
   # Stand at the bar, in front of him, looking north at him
   setCharacterStandPoint (barman, 0, 40, NORTH);
   moveCharacter (ego, barman);
   say (ego, "A glass of your finest tap water, please.");
}

panCamera

Syntax:

panCamera (x, y);

Purpose:

Glides the camera until the point (x, y) is in the centre of the window, and waits until it gets there. It ends up exactly where aimCamera would have put it.

The camera moves with the speed, ease-in and ease-out set by setCameraSpeed. That makes it handy for cut-scenes: show the player the door that just opened, then glide back.

panCamera stops the camera following a character. If you want it to follow one again afterwards, call trackCharacter. If you don't want to wait for the camera, call panCamera from a function started with spawnSub.

Return value:

No return value.

Example:

objectType ego ("Ego") {
}

sub showTheDoor () {
   setCameraSpeed (5, 20, 20);
   panCamera (1600, 240);
   say (ego, "The door! It's open!");
   trackCharacter (ego);
}

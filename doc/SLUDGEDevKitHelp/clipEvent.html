clipEvent

Syntax:

clipEvent (clip, tick, soundOrFunction);

Purpose:

Runs an event during playback of a clip. When clip passes tick, it plays a sound file, or starts a function (without parameters). Events fire whether the character is shown or not.

tick can be anything from 0 to the length of the clip. An event at tick 0 happens when the clip starts. If the clip loops, it happens again each time the clip starts over. An event at the last tick happens when the clip reaches its end. If the clip loops, that is at the end of every round. 

var walk = newClip (32, TRUE);
clipEvent (walk, 0, 'step.wav');
clipEvent (walk, 8, 'step.wav');
clipEvent (walk, 30, someFunction);

Return value:

None.

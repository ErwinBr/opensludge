clipEvent

Syntax:

clipEvent (clip, tick, soundOrFunction);

Purpose:

Plays a sound, or calls a function, when clip gets to tick.

soundOrFunction is either a sound file, in single quotes, or the name of a function that takes no parameters. Anything else stops the game with an error. Footsteps are the classic use: a step sound at the two ticks where the feet touch the ground.

tick can be anything from 0 to the length of the clip. An event at tick 0 happens when the clip starts, and an event at the last tick when the clip reaches its end. If the clip loops, they happen again in every round.

Events happen whether the character is shown or not, which is different from the sounds and functions of anim. So hiding a character doesn't silence its footsteps: stop the clip for that.

Return value:

No return value.

Example:

sub lookAround () {
   # Called near the end of every step
}

sub walk () {
   var c = newClip (32, TRUE);
   clipEvent (c, 0, 'step.wav');
   clipEvent (c, 16, 'step.wav');
   clipEvent (c, 30, lookAround);
   return c;
}

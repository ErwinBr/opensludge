clipEvent

Syntax:

clipEvent (clip, tick, soundOrFunction);

Purpose:

When clip passes tick, it plays the sound file, or starts the function (without parameters), as the frames of anim can. The tick lies from 0 to the length of the clip: at 0, the event fires as the clip starts and each time a loop goes round; at the length, as each pass ends, or as a clip that doesn't loop finishes.

Events fire whether the character is shown or not. See Animation Clips for their order. 

clipEvent (walk, 0, 'step.wav');
clipEvent (walk, 8, 'step.wav');
clipEvent (wave, 30, waveDone);	# as the wave finishes

Return value:

None.

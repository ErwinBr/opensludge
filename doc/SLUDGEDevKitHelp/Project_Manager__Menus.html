The Menus of the Dev Kit

These are the menus of the SLUDGE Dev Kit. On macOS, use Command where it says Ctrl.

File menu:

New: makes a new project, floor, z-buffer, sprite bank or translation. A new project asks first where to save it, since its files are relative to its folder; the others ask when you save them.

Open... (Ctrl+O): opens a project or a file that the Dev Kit edits.

Open Recent: the files that you opened last.

Save (Ctrl+S), Save As... (Ctrl+Shift+S) and Save All: save the file in the tab at the front, under another name, or every file with changes.

Close (Ctrl+W): closes the tab at the front, after asking whether to save its changes.

Quit (Ctrl+Q): quits the Dev Kit, after asking about each file with changes.

Edit menu:

Undo (Ctrl+Z) and Redo (Ctrl+Shift+Z): take back the last change of the file in front, and make it again. The menu says what they take back.

Preferences...: the preferences of the Dev Kit.

Project menu:

Add Files...: adds scripts, constant definitions and translations to the project.

Properties: shows the settings of the project in the Inspector.

Check Files...: finds what keeps the project from building on every system, such as scripts that aren't UTF-8 and file names in another case than on disk, and fixes it.

Compile (Ctrl+B): saves the project and compiles it into a SLUDGE game (.SLG) file, which has the name of the Game file setting. The Build panel shows the progress, the errors and the warnings. While it compiles, Cancel Compile stops it.

Run Game (Ctrl+R): plays the compiled game in the SLUDGE engine.

Close Project: closes the project.

View menu:

Shows and hides the Project, Build, Inspector and Log panels. Reset Layout puts every panel back in its first place.

Help menu:

SLUDGE Dev Kit Help: opens this help. SLUDGE Website opens the website of SLUDGE, and About the SLUDGE Dev Kit shows its version.

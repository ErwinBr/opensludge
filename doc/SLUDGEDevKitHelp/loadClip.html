loadClip

Syntax:

loadClip ('clipFile');

Purpose:

Loads an animation clip that you made in the Animation Editor of the Dev Kit: a .clp file of your project, with all its tracks, keys and events. You get the same clip as one you build with newClip, so you use it in the same ways: in a costume, with animate, on a layer with playClip, or mirrored with mirrorClip. Until you use it, you can still add keys and events to it.

A clip moves parts by their names, so it plays on the rig that you made it for, and on any other rig with parts of the same names (see Composite Characters).

Name the file in single quotes, from the folder of your project. The compiler puts the clip into your game, with the sprite banks and sounds that it uses. It tells you, with the script and line that load the clip, when a bank or sound is missing, or when an event calls a function that your scripts don't have. It warns you when the clip has tracks for parts that its rig doesn't have: those tracks do nothing. 

sub egoCostume () {
	return costume (
		loadClip ('ego/stand_south.clp'), loadClip ('ego/stand_west.clp'), loadClip ('ego/stand_north.clp'), loadClip ('ego/stand_east.clp'),
		loadClip ('ego/walk_south.clp'), mirrorClip (loadClip ('ego/walk_east.clp')), loadClip ('ego/walk_north.clp'), loadClip ('ego/walk_east.clp'),
		loadClip ('ego/talk_south.clp'), loadClip ('ego/talk_west.clp'), loadClip ('ego/talk_north.clp'), loadClip ('ego/talk_east.clp'));
}

sub startBlinking () {
	playClip (ego, 2, loadClip ('ego/blink.clp'));	# On a layer of its own
}

Return value:

The clip.

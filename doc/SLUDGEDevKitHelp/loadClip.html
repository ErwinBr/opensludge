loadClip

Syntax:

loadClip (clipFile);

Purpose:

Loads an animation clip that you made in the Animation Editor, so you don't have to type in every key with clipKey.

clipFile is a .clp file of your project, in single quotes, just like a sprite bank or a sound. You get exactly the same thing as a clip built with newClip, with all its tracks, keys and events, and you use it in the same ways: in a costume, with animate, on a layer with playClip, or mirrored with mirrorClip. Until you use it, you can still add keys and events to it. Give it anything other than a clip, such as a .rig file, and the game stops with an error.

A clip moves parts by their names, so it plays on the rig you made it for, and on any other rig with parts of the same names (see Composite Characters).

The compiler puts the clip into your game, with the sprite banks and sounds it uses. It tells you, with the script and line that load the clip, when a bank or sound is missing, or when an event calls a function your scripts don't have. It also warns you about tracks for parts that the clip's rig doesn't have, because those tracks would do nothing.

Return value:

Returns the clip.

Example:

objectType ego ("Ego") {
}

sub startBlinking () {
   playClip (ego, 2, loadClip ('ego/blink.clp'));    # On a layer of its own
}

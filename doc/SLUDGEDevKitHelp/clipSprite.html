clipSprite

Syntax:

clipSprite (clip, part, tick, spriteBank, sprite);
clipSprite (clip, part, tick, NOSPRITE);
clipSprite (clip, part, tick, PART_DEFAULT);

Purpose:

From tick in clip, makes part show sprite from spriteBank.

The part keeps that sprite until the next sprite key of the same part. A negative sprite shows its mirror image, as in anim. For a character without parts, or for the character as a whole, use "" as the part.

With NOSPRITE, the part shows nothing at all, which is handy for closed eyes. With PART_DEFAULT, it goes back to the sprite you gave the part with addPart.

Sprites never ease: there's no such thing as halfway between two sprites, so the part changes exactly at the key's tick.

Return value:

No return value.

Example:

sub blink () {
   var c = newClip (40, TRUE);
   clipSprite (c, "eyes", 0, 'eyes.duc', 4);     # Eyes open...
   clipSprite (c, "eyes", 36, 'eyes.duc', 5);    # ...half closed...
   clipSprite (c, "eyes", 38, NOSPRITE);        # ...and closed, so we show nothing
   return c;
}

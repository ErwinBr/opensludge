setPartPivot

Syntax:

setPartPivot (rig, name, x, y);

Purpose:

Sets the pivot of the part called name in rig: the point that the part turns, scales and flips around.

Normally a part turns around the hotspot of its sprite, which you set in the Sprite Bank Editor. That's fine until you have an arm whose hotspot is in the middle, and it spins like a propeller instead of swinging from the shoulder. The pivot moves that point by x, y pixels of the sprite (+X is right, +Y is down), without touching the sprite bank, which other parts or characters may be using too.

The pivot is also the point that the x and y of addPart place. So setPartPivot moves the sprite around that point, and the part's place, and the parts hanging from it, stay where they are. (In the Character Creator it's the other way round: dragging the pivot keeps the sprite where it is, and moves the part.)

Call it while you build the rig, before you give the rig to a character with setCharacterRig, because after that the rig can't change. A name that isn't a part of the rig stops the game with an error.

Return value:

No return value.

Example:

sub armRig () {
   var r = newRig ();
   addPart (r, "torso", "", 0, -150, 'torso.duc', 0);
   addPart (r, "arm", "torso", 40, -90, 'arm.duc', 0);   # The arm's hotspot is in its middle...
   setPartPivot (r, "arm", 0, -60);                     # ...so it swings from 60 pixels higher up
   return r;
}

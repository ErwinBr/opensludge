setClipSpeed

Syntax:

setClipSpeed (character, layer, percent);

Purpose:

Plays what character is playing on layer at percent of its normal speed.

100 is normal, 50 is half speed, 200 is twice as fast, and 0 pauses it. Anything below 0 or above 100000 gives an error. It works for clips and for animations of anim, which makes slow motion easy.

On layers 1 to 99, the layer has to be playing already, so call setClipSpeed after playClip. Playing a new clip on the layer sets its speed back to 100%. The speed of layer 0, the costume's layer, stays for the animations that come after it.

Return value:

On layer 0, returns TRUE if there is such a character, otherwise FALSE. On the other layers, returns FALSE as well when nothing plays on the layer.

Example:

objectType ego ("Ego") {
}

sub slowMotion () {
   setClipSpeed (ego, 0, 50);
}

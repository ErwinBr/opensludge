stopClip

Syntax:

stopClip (character, layer);

Purpose:

Stops the clip on layer of character, and takes the layer away.

Whatever the layer did to the character's parts goes with it, so the parts go back to what the layers below say. Use it for layers 1 to 99. Layer 0 belongs to the costume and can't be stopped: trying gives an error. If nothing is playing on the layer, nothing happens.

Return value:

Returns FALSE if there's no such character, otherwise TRUE, even if nothing was playing on the layer.

Example:

objectType ego ("Ego") {
}

sub stopWaving () {
   stopClip (ego, 2);
}

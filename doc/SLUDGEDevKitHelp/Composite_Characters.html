Composite Characters

A normal SLUDGE character is one sprite at a time. Want it to wave? Draw every frame of the wave. Want it to wave while it walks? Draw every frame of that too... and the same again for talking while it waves, and so on, until you run out of patience or disk space.

Since SLUDGE 2.3, a character can be made of separate parts instead, like a puppet: a torso with a head on it, a pair of eyes in the head, arms that hang from the shoulders. Each part has sprites of its own, and you can move, turn, scale, hide or colour each one on its own. Wave an arm while the legs walk, blink while you talk, and draw each sprite just once.

The rig:

A rig is the list of parts that a character is made of, and how they hang together. The easiest way to make one is in the Character Creator of the Dev Kit, where you can see what you're doing. It saves the rig as a .rig file, and your script loads it with loadRig. You can also build a rig in a script, with newRig and addPart. Either way, how the parts stand in the rig is the character's rest pose: how it stands when nothing moves it.

Give the rig to a character with setCharacterRig. Build the whole rig first, because from that moment the rig is in use and can't change: you can't add parts any more, or change their pivots or depths, not even for other characters that get the same rig later. To move the parts after that, use Animation Clips, or set their properties straight from your script with setPartProperty.

Parts:

Each part hangs from another part, its parent, or from the character itself. A part's origin is the hotspot of its sprite, which you set in the Sprite Bank Editor, or a point of its own: its pivot (see setPartPivot). Its x and y say where that origin is, measured from its parent's origin: +X is right, +Y is down. A part turns (clockwise, in degrees) and scales around its origin.

Whatever you do to a part, you do to the parts hanging from it too. Turn the torso, and the head and arms turn with it, and then each of them can turn a bit further on its own. Which part is drawn in front of which is up to their depths (see setPartDepth), so the far arm can go behind the body.

Each part can have a colour of its own too, which its sprite is multiplied by, on top of the character's light, colourise and transparency. Modulate colours the part and the parts hanging from it, and Self Modulate colours the part only. Each has a red, green, blue and alpha (opacity) from 0 to 200%, where 100% leaves the sprite as it is. Rigs and clips can set them, and so can your script, with clipKey and setPartProperty.

It's still one character:

Apart from all that, a composite character works just like any other character. The mouse is over it when it points at a visible pixel of any of its parts. With RECTANGULAR (see setCharacterExtra), SLUDGE puts an invisible box around all the parts together instead, and the mouse is over the character anywhere inside it. pasteCharacter pastes all the parts together, and the z-buffer, the light map, transparency and the other effects apply to the character as a whole.

An example:

This builds a rig in a script, and gives the character a costume of clips that set the sprites of its parts: 

objectType hero ("Hero") {
}

sub heroRig () {
   var r = newRig ();
   addPart (r, "legs", "", 0, 0, 'hero/legs.duc', 0);      # "" is the character itself
   addPart (r, "torso", "", 0, -250, 'hero/torso.duc', 0);
   addPart (r, "head", "torso", 3, -213, 'hero/head.duc', 0); # The head hangs from the torso
   addPart (r, "eyes", "head", 0, 0, 'hero/head.duc', 6);
   addPart (r, "arm", "torso", -60, -150, 'hero/arm.duc', 0);
   setPartDepth (r, "arm", -1);                              # Behind the torso, which is at 0
   return r;
}

sub stand (bank) {
   # A clip of length 0 is one pose: just the thing for standing still
   var c = newClip (0);
   clipSprite (c, "legs", 0, bank, 0);
   clipSprite (c, "torso", 0, bank, 1);
   clipSprite (c, "head", 0, bank, 2);
   clipSprite (c, "eyes", 0, bank, 3);
   clipSprite (c, "arm", 0, bank, 4);
   return c;
}

sub heroCostume () {
   var walkEast = loadClip ('hero/walk_east.clp');
   return costume (
      stand ('hero/south.duc'), stand ('hero/west.duc'), stand ('hero/north.duc'), stand ('hero/east.duc'),
      loadClip ('hero/walk_south.clp'), mirrorClip (walkEast), loadClip ('hero/walk_north.clp'), walkEast,
      loadClip ('hero/talk_south.clp'), loadClip ('hero/talk_west.clp'), loadClip ('hero/talk_north.clp'), loadClip ('hero/talk_east.clp'));
}

sub init () {
   addCharacter (hero, 320, 400, heroCostume ());
   setCharacterRig (hero, heroRig ());
}

With a rig made in the Character Creator, and clips made in the Animation Editor, it's a lot shorter: 

sub init () {
   addCharacter (hero, 320, 400, costume (loadClip ('hero/stand.clp'), loadClip ('hero/walk.clp'), loadClip ('hero/talk.clp')));
   setCharacterRig (hero, loadRig ('hero/hero.rig'));
}

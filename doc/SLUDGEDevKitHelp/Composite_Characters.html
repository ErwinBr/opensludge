Composite Characters

As of SLUDGE 2.3: A character can consist of separate parts, each represented with individual sprites (and animations). Parts have a hierarchical relationship. The character can have a torso, the torso a head, the head a set of eyes.

Rig

A rig defines the parts of a Composite Character. The easiest way to make one is in the Character Creator of the Dev Kit, which saves it as a .rig file; your script loads that with loadRig. You can also build a rig in a script: make it with newRig, and add parts to it. The parts and their properties are the rest pose of the character: how it stands when no animation moves it.

Build the rig completely before you give it to a character. As soon as you call setCharacterRig with it, the rig is in use and fixed: you can't add parts to it or change their depth any more, not even for other characters that get the same rig later. To change the look of the parts after that, use Animation Clips, or set their properties directly with setPartProperty.

Parts

A part's origin is the hotspot of its sprite, as you set it in the Sprite Bank Editor, or a point of the sprite of its own, its pivot (see setPartPivot). Its x and y say where that origin sits, measured from its parent's origin: +X is right, +Y is down. A part turns (clockwise, in degrees) and scales about its origin. Whatever you do to a part, you also do to the parts attached to it: turn the torso and the head and arms turn with it, and then each can turn further on its own.

A composite character works like any other character. The mouse is over it when it points at a visible pixel of any of its parts. pasteCharacter pastes all its parts together, as one character. The z-buffer, the light map, transparency and other effects apply to the character as a whole, and so on.

With RECTANGULAR (see setCharacterExtra), SLUDGE puts an invisible box around all the parts together, and the mouse is over the character anywhere inside that box. 

sub heroRig () {
	var r = newRig ();						# Create a new rig and add parts to it (rest pose).
	addPart (r, "legs", "", 0, 0, 'hero_legs.duc', 0);		# Add legs. The "" means its parent is the character itself.
	addPart (r, "torso", "", 0, -250, 'hero_torso.duc', 0);
	addPart (r, "head", "torso", 3, -213, 'hero_head.duc', 0); 	# The head is parented to the torso.
	addPart (r, "eyes", "head", 0, 0, 'hero_head.duc', 6);
	addPart (r, "arm", "torso", -60, -150, 'hero_arm.duc', 0);
	setPartDepth (r, "arm", -1);					# -1 draws the arm behind the torso, which has depth 0
	return r;
}

sub heroCostume () {							# A standard costume. The stand function below further illustrates how to use parts and clips.
	return costume (
		stand (SOUTH), stand (WEST), stand (NORTH), stand (EAST),
		walk (SOUTH), mirrorClip (walk (EAST)), walk (NORTH), walk (EAST),
		talk (SOUTH), talk (WEST), talk (NORTH), talk (EAST));
}

sub stand (dir) {							# An example of a standing animation, used in the costume above.
	var c = newClip (0);
	if (dir == SOUTH) {
		clipSprite (c, "legs", 0, 'legs_south.duc', 0);
		clipSprite (c, "torso", 0, 'torso_south.duc', 0);
		clipSprite (c, "head", 0, 'head_south.duc', 0);
		clipSprite (c, "eyes", 0, 'head_south.duc', 6);		# The eyes are on frame 6 in the spritebank
		clipSprite (c, "arm", 0, 'arm_south.duc', 0);
		clipKey (c, "head", PART_X, 0, 3);			# Position the head
		clipKey (c, "head", PART_Y, 0, -213);
		clipKey (c, "head", PART_DEPTH, 0, 2);			# Draw the head on top of its parent (the torso)
	} else if (dir == NORTH) {
		...
	return c;
}

addCharacter (hero, 320, 400, heroCostume ());			# Create a character and set its costume.
setCharacterRig (hero, heroRig ());				# Assign the rig created on top of this example to the character.

The same with a rig made in the Character Creator, and clips made in the Animation Editor: 

addCharacter (hero, 320, 400, costume (loadClip ('hero/stand.clp'), loadClip ('hero/walk.clp'), loadClip ('hero/talk.clp')));
setCharacterRig (hero, loadRig ('hero/hero.rig'));

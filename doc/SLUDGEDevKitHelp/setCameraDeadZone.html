setCameraDeadZone

Syntax:

setCameraDeadZone (width, height);

Purpose:

Lets the character the camera follows (trackCharacter) wander around a box in the middle of the window, width by height pixels, without the camera moving.

When the character steps out of the box, the camera goes along with it, so that the character stays on the edge of the box. That way, a character taking a couple of steps doesn't make the whole scene shuffle about.

A box of 0 by 0, as when the game starts, keeps the character in the centre. To scroll only sideways, make the box as tall as the window. Neither number can be below 0.

Return value:

No return value.

Example:

sub init () {
   # The character can walk 100 pixels either side of the
   # centre, and anywhere up and down.
   setCameraDeadZone (200, 480);
}

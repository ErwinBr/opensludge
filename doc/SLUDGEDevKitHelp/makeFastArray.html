makeFastArray

Syntax:

makeFastArray (numberOfElements);
makeFastArray (thisStack);

Purpose:

Creates a fast array: a list of a fixed size, which you read and set with square brackets just like a stack, but much faster to read by number.

If you give it a number, the new array has numberOfElements elements, all of them NULL. If you give it a stack, the new array has as many elements as thisStack and holds a copy of each of them, in the same order. Changing the stack afterwards doesn't change the array.

So why bother? A stack is a chain of elements, so to find myStack[500] SLUDGE has to walk past the 500 elements before it. A fast array goes straight to the element you ask for, however big it is. If you keep a big table of values and read it by number, a fast array is much quicker.

The catch is that its size never changes. You can read and set its elements with square brackets, and stackSize tells you how many there are, but the other stack functions (pushToStack, popFromStack, enqueue and friends) only work on stacks, and will stop the game with an error if you give them a fast array. Reading an element past the end gives you NULL, but setting one is an error! Like a stack, a fast array counts as TRUE when it has any elements, and copying it into another variable doesn't copy the elements: both variables then point at the same array.

Return value:

Returns the new fast array.

Example:

objectType ego ("Ego") {
}

var squares;

sub init () {
   squares = makeFastArray (100);
   var i = 0;
   while (i < 100) {
      squares[i] = i * i;
      i ++;
   }
   say (ego, "Seven squared is " + squares[7] + ".");
}

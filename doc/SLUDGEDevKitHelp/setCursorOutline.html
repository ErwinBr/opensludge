setCursorOutline

Syntax:

setCursorOutline (thickness, red, green, blue, alpha);

Purpose:

Draws an outline around the mouse cursor, thickness pixels thick, in the colour red, green, blue and alpha. A thickness of 0 takes the outline away again.

thickness goes from 0 to 64 pixels of the screen, and the colour values from 0 to 255, as for setCharacterOutlineColour. The outline follows the shape of whatever cursor you set with setCursor, and stays when you change the cursor, so it's handy for showing that the item you're carrying around can be used on whatever the mouse is over.

Saved games remember the cursor's outline, and freezing doesn't change it.

Return value:

No return value.

Example:

sub showItemCanBeUsed (canBeUsed) {
   if (canBeUsed) {
      setCursorOutline (2, 255, 255, 255, 255);
   } else {
      setCursorOutline (0, 0, 0, 0, 0);
   }
}

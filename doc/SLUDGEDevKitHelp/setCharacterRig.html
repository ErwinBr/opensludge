setCharacterRig

Syntax:

setCharacterRig (character, rig);
setCharacterRig (character, 0);

Purpose:

Gives character the parts of rig, so that it's drawn as a Composite Character instead of as one sprite.

The rig can come from newRig, if you built it in your script, or from loadRig, if you made it in the Character Creator. Give 0 instead of a rig to turn the character back into an ordinary one, with a single sprite.

From now on, the clips of the character's costume, and the clips you give to animate, move its parts by their names. An animation made with anim moves the character as a whole.

Add the character with addCharacter first: there's nobody to give the rig to otherwise. Once a character uses the rig, the rig can't change any more, so add all its parts, pivots and depths before you call this. To move the parts after that, use clips (see Animation Clips) or setPartProperty.

Return value:

Returns TRUE if there is such a character, otherwise FALSE.

Example:

objectType ego ("Ego") {
}

sub init () {
   addCharacter (ego, 320, 400, anim ('ego.duc', 0));
   setCharacterRig (ego, loadRig ('ego/ego.rig'));
}

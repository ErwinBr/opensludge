Project Settings

The settings of the open project are in the Inspector: click the Project panel, or choose Project > Properties. A change is part of the project like any other, so you can undo it, and it is saved with the project.

Game

Window title: the text which will be visible in the title bar of the game when it's running.

Game file: the name of the game file to be created by the SLUDGE compiler when the project is compiled. The extension ".SLG" will be added automatically - please don't add this yourself. The name entered here is also used for a file containing all the strings in your game - see the Spellchecking the Strings in your Game topic.

Language: the language of the strings in your code. This is used in the language selection field of the SLUDGE Engine. The names of additional languages (translations) are specified in the translation editor when they are created.

Save folder: any run-time files which your SLUDGE game uses (i.e. any custom data or saved game files) will be created in (and loaded from) the application data folder of the game (%APPDATA%\Game Name on Windows, $HOME/.sludge-engine/Game Name on Linux and ~/Library/Application Support/SLUDGE/Game Name on macOS). Should you want to keep these run-time files in a subfolder instead, enter the name of the folder here. The folder need not exist already - when your game starts, it will create the folder if it doesn't already exist. The name you specify must be a valid filename... i.e. no illegal characters, such as ":", "/", "\", "?", "*" or "|".

Quit message: the prompt to be displayed when a player tries to quit by closing the window of the game. The prompt will not appear in response to a call to the quitGame command, which always closes the game immediately.

Icon: an icon to be used in your game's title bar, plus in the taskbar and in the window that appears should a player switch between programs. Leave it empty to use the normal SLUDGE icon. Choose the file with the ... button.

Logo: a logo that is shown while the game starts instead of the SLUDGE logo. It must be 310x88 pixels large.

Window

Width and Height: the size of the window you wish your game to use, in pixels.

Frame time: the minimum time, in milliseconds, for which each frame should be displayed on-screen. The lower the number, the faster your game will run... provided it is being run on a machine which is capable of the speed requested. Higher numbers mean your game will run more slowly on a fast machine, but will act consistently across different specifications. If you're more used to thinking in terms of how many frames you'll get per second, that figure is 1000 divided by the milliseconds per frame value... eg. 25 milliseconds per frame gives (1000 / 25 =) 40 frames per second.

Full screen: start the game in full screen. Invisible: start it without a window. System mouse: show the mouse pointer of the system over the game. Logo and Loading: show the logo and the loading screen while the game starts. Dither: dither the images, for displays with few colours.

Silent: the compiler will create a silent game - no sounds or movies. The sound and movie files won't be included in the game file. This can be useful if you have a lot of sound or movies, as this will then result in a much smaller game file and a shorter compile time.

Character rendering

Soften softens the characters by default, by Softness X and Softness Y. Limit limits the softness to Most X and Most Y, and Player limit reads that limit from the settings of the player instead.

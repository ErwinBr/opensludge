Preferences

Edit > Preferences opens the preferences of the Dev Kit, which apply to every project. The Dev Kit saves them as you change them.

Compiler

Keep the compressed images: if this option is checked, the compressed images generated during compilation will be kept on your machine after compilation. This will take up extra space but will decrease the time it takes to compile a project, as during subsequent compilations any images which have not changed do not need to be recompressed.

Write the strings to a text file: during compilation, generate a file containing all the strings used in your game. Useful if you want to spellcheck the strings without also spellchecking your SLUDGE code.

Verbose errors (development mode): include function names and other debugging information in your compiled game. This means that run-time error messages are more meaningful. It's recommended that you keep this option checked while developing a game, and uncheck it before compiling a release version.

Programs

The programs that open the files of a project when you double-click them: an image viewer for PNG and TGA images, an audio player for WAV, OGG and FLAC sounds, and a module player for MOD, S3M, IT and XM music. Leave one empty for the program that your system opens the file with. Scripts and constant definitions open in the Dev Kit's own script editor, as does a double-click on an error, at its line.

Write {file} where the name of the file goes. Without it, the file goes at the end. For example, for an image viewer:

eog {file}

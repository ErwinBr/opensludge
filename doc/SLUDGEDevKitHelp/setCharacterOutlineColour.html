setCharacterOutlineColour

Syntax:

setCharacterOutlineColour (thisCharacter, red, green, blue, alpha);

Purpose:

Sets the colour of the outline that thisCharacter has in the OUTLINE draw mode.

red, green, blue and alpha go from 0 to 255. An alpha of 255 makes a solid outline, and 128 one that you can half see through. A new character has a white outline (255, 255, 255, 255). Anything outside 0 to 255 stops the game with an error, rather than guessing what you meant.

The colour stays with the character, but you only see it while the character's draw mode is OUTLINE (see setCharacterDrawMode), so you can set it once when the character arrives and switch the outline on and off later. Unlike the character, the outline isn't darkened by the light map. If you make the character see-through with setCharacterTransparency, its outline fades with it, and goes round the character without showing through it.

setCharacterOutlineColor works too.

Return value:

No return value.

Example:

objectType ego ("Ego") {
}

sub highlightEgo () {
   setCharacterOutlineColour (ego, 255, 220, 0, 255);
   setCharacterOutlineThickness (ego, 3);
   setCharacterDrawMode (ego, OUTLINE);
}

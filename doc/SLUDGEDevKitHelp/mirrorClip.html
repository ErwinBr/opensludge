mirrorClip

Syntax:

mirrorClip (clip);

Purpose:

Makes a copy of clip in which the character is flipped horizontally. It does that by flipping the character from the root, which mirrors every part attached to it. A part you flipped with PART_FLIP stays flipped relative to its parent, so in the copy it is mirrored along with the rest, exactly like a mirror image. If the clip already flips the root, the copy unflips it. A costume can use it to walk WEST using a clip that walks EAST.

mirrorClip only takes a clip of newClip, not an animation of anim (use a negative sprite number in anim instead). The copy is a new clip that you can still add keys to; the original stays as it was.

Note: On a Composite Character, mirror a single part by keying its PART_FLIP property with clipKey instead. 

costume (standSouth, mirrorClip (standEast), standNorth, standEast,
	walkSouth, mirrorClip (walkEast), walkNorth, walkEast,
	talkSouth, mirrorClip (talkEast), talkNorth, talkEast)

Return value:

The new clip.

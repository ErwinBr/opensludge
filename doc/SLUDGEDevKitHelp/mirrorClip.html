mirrorClip

Syntax:

mirrorClip (clip);

Purpose:

Makes a mirror-image copy of clip, so that a costume can walk WEST with the clip that walks EAST.

Why draw everything twice? mirrorClip flips the whole character, from the character itself down, so every part is mirrored along with it. A part that the clip flips with PART_FLIP stays flipped compared to its parent, so the copy really is a mirror image. If the clip already flips the whole character, the copy unflips it.

The copy is a new clip, which you can still add keys to, and the original stays as it was. mirrorClip only takes clips: for an animation of anim, use negative sprite numbers instead, or the game stops with an error. To mirror just one part of a Composite Character, key its PART_FLIP with clipKey.

Return value:

Returns the new clip.

Example:

sub egoCostume () {
   var standEast = loadClip ('ego/stand_east.clp');
   var walkEast = loadClip ('ego/walk_east.clp');
   var talkEast = loadClip ('ego/talk_east.clp');
   return costume (
      loadClip ('ego/stand_south.clp'), mirrorClip (standEast), loadClip ('ego/stand_north.clp'), standEast,
      loadClip ('ego/walk_south.clp'), mirrorClip (walkEast), loadClip ('ego/walk_north.clp'), walkEast,
      loadClip ('ego/talk_south.clp'), mirrorClip (talkEast), loadClip ('ego/talk_north.clp'), talkEast);
}

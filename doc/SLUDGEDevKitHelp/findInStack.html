findInStack

Syntax:

findInStack (thisStack, thisElement);

Purpose:

Tells you where thisElement is in thisStack, without changing the stack.

The standard SLUDGE equality test is performed on each element of the stack and the value of thisElement, starting at the front - the same test that deleteFromStack uses. So two strings match if they hold the same text, but two stacks only match if they're the very same stack: a copy made with copyStack doesn't count, however alike the two look.

The number you get back counts from 0, just like the square brackets do, so you can use it straight away to read the element or to change it. If thisElement is in the stack more than once, you get the first one.

thisStack has to be a stack. A fast array, or anything else, stops the game with an error.

Return value:

The position of the first element which matches thisElement, where 0 is the first element of the stack, or -1 if there's no match at all.

Example:

sub swapInventoryItem (oldItem, newItem) {
	var where = findInStack (inventory, oldItem);
	if (where == -1) return FALSE;
	inventory[where] = newItem;
	return TRUE;
}

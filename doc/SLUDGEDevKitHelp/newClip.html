newClip

Syntax:

newClip (length);
newClip (length, loop);

Purpose:

Creates a new, empty animation clip that lasts length ticks (screen updates).

If loop is TRUE, the clip plays over and over. Without it, or with FALSE, the clip plays once and then holds its last frame. A clip of length 0 shows one pose and stays there, which is just the thing for standing still. A negative length stops the game with an error.

Fill the clip with clipSprite, clipKey, clipFrames and clipEvent. Then use it wherever you would use an animation of anim: with animate, costume, addCharacter, setCursor or pasteImage, or on a layer of its own with playClip.

Add all its keys and events first! As soon as you use the clip in any of those ways it's fixed, because a character may be playing it, and adding a key or event to it after that gives an error.

Return value:

Returns the new clip.

Example:

objectType ego ("Ego") {
}

sub wave () {
   var c = newClip (30);
   clipSprite (c, "", 0, 'ego.duc', 12);
   clipSprite (c, "", 10, 'ego.duc', 13);
   clipSprite (c, "", 20, 'ego.duc', 12);
   pause (animate (ego, c));
}

setScaleMap

Syntax:

setScaleMap (imageFile, smallest, largest);
setScaleMap (NULL);

Purpose:

Sets a scale map, loading it from the imageFile file: a greyscale picture of the scene which tells the engine how big a character is wherever it stands. Black means smallest per cent, white means largest per cent, and the greys come somewhere in between.

setScale works out a character's size from how far down the screen its feet are, which is just right for a floor that goes off into the distance. It's no good for a platform, a staircase or a hill, though: a character standing on a high platform near the camera has its feet high up the screen, but should still be big. With a scale map, you paint the size instead. Load the background into your paint program, put a new layer over it, and paint the floor in greys: darker where characters should be small, lighter where they should be big. A smooth gradient gives a smooth change in size as a character walks along, and a hard edge gives a jump. Then save the layer on its own as a PNG.

The engine looks at the pixel under the character's hotspot (the point at its feet), so it's only the parts of the map that characters can stand on that matter. The rest can be any colour you like. If you paint in colour by mistake, the engine takes the average of the red, green and blue values.

The map doesn't have to be the same size as the scene. To save memory, you can make it half or a quarter of the size, and the engine will stretch it over the whole scene. It blends the pixels where it stretches them, so a small map doesn't make the characters grow and shrink in steps. Scale maps are usually gentle gradients, so a small one rarely looks any different.

A scale map takes over from setScale straight away, for every character, even ones that are standing still. Characters also walk more slowly where the map makes them smaller, just as they do with setScale. Characters whose extra properties - set using setCharacterExtra - include the FIXEDSIZE option aren't affected by the scale map.

If imageFile is NULL (or anything other than a file handle), the current scale map is removed, and characters are scaled using the settings from setScale again, straight away. The scale map belongs to the scene, like the light-map and the z-buffer, so setSceneDimensions removes it too. Freezing the scene and saving the game both keep it.

Return value:

Returns TRUE if a scale map was loaded, or FALSE if it was removed.

Example:

sub enterBalcony () {
   setSceneDimensions (640, 480);
   addOverlay ('balcony.tga', 0, 0);
   setFloor ('balcony.flo');
   # Small at the back (40%), full size on the balcony at the front
   setScaleMap ('balconyScale.png', 40, 100);
}

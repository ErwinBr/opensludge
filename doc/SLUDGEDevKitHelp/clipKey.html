clipKey

Syntax:

clipKey (clip, part, property, tick, value);
clipKey (clip, part, property, tick, value, easing);

Purpose:

Changes properties of a character's part during the playback of an animation clip. At tick, the property of part is value. From there it moves towards the value of the next key, and reaches it at that key's tick. tick may be from 0 to the length of the clip.

Properties you can change:

  • PART_X, PART_Y: The part's local X and Y coordinates.
  • PART_ROTATION: Rotation in degrees, measured clockwise.
  • PART_SCALE: Size in percentage, the same in width and height. 100 = full size, 50 = half, 200 is double, etc...
  • PART_SCALE_X, PART_SCALE_Y: Size in percentage of the width or the height only, along the part's own axes. In a clip that has both, PART_SCALE_X and PART_SCALE_Y win over PART_SCALE.
  • PART_DEPTH: The order of drawing relative to other parts. For example, to draw an arm behind its body. (see setPartDepth)
  • PART_VISIBLE: Set visibility to TRUE or FALSE. FALSE hides the part and the parts attached to it.
  • PART_FLIP: TRUE mirrors the part, and the parts attached to it.

The easing says how the current key moves towards the next key:

  • EASE_LINEAR properties change at a steady speed (the default value)
  • EASE_INOUT slow at the start, slow at the end
  • EASE_STEP properties hold their value until the next key.
PART_DEPTH, PART_VISIBLE and PART_FLIP always step, whatever easing you give them, because they have no values in between.

The easing you give a key decides how the property moves from that key to the next one. The last key is where the movement ends: the property moves towards it with the easing of the key before it. If you give the last key an easing as well, it has no effect, because no movement starts there.

In the Animation Editor, the easing of a key is its "Towards the next key" in the Inspector, and the colour of the key on the timeline.

Before the first key, the property keeps the value of that first key. After the last key, it keeps the value of the last key. 

var c = newClip (48, TRUE); 				# Create a new clip: Duration: 48 ticks, looping = true
clipKey (c, "torso", PART_Y, 0, -250, EASE_INOUT); 	# The torso of a character's Y position starts at -250 and eases to -262 at tick 24...
clipKey (c, "torso", PART_Y, 24, -262, EASE_INOUT); 	# ...then eases back to -250 at tick 48.
clipKey (c, "torso", PART_Y, 48, -250); 		# Last tick (48): the target of the movement before it.

Return value:

None.

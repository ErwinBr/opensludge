playClip

Syntax:

playClip (character, layer, clip);
playClip (character, layer, clip, LAYER_OVERRIDE);
playClip (character, layer, clip, LAYER_ADD);

Purpose:

Plays clip on layer of character, on top of what the character is already doing.

Layers let a character do several things at once: walk on its costume, blink on layer 1 and wave on layer 2. Use layers 1 to 99. Layer 0 belongs to the costume, so playing a clip there gives an error: use animate for that. Higher layers go on top of lower ones.

LAYER_OVERRIDE is what you get if you leave it out. The layer sets whatever its clip keys, and leaves everything else to the layers below it, so a waving clip that only keys the arm leaves the legs walking. With LAYER_ADD, the layer adds its values instead: it adds to the position (PART_X, PART_Y) and angle (PART_ROTATION), and multiplies the sizes and colours, where 100 leaves them as they are. That's how you get a gentle breathing movement on top of any walk. Sprites, visibility, depth and flipping can't be added to: even on an additive layer they are just set, and the highest layer that keys them wins.

Playing a clip on a layer that already has one replaces it, and sets the layer's speed back to 100% (see setClipSpeed). Each layer has its own time and its own events. A clip that doesn't loop holds its last pose when it ends, until you take it away with stopClip, which stops a looping clip too.

playClip only plays clips. To play an animation of anim on a layer, turn it into a clip with clipFrames first, or the game stops with an error.

Return value:

Returns the length of the clip in ticks, at normal speed, so that pause (playClip (...)) waits until it ends. For a looping clip, that's the length of one round.

Example:

objectType ego ("Ego") {
}

sub greet () {
   playClip (ego, 1, loadClip ('ego/breathe.clp'), LAYER_ADD);
   pause (playClip (ego, 2, loadClip ('ego/wave.clp')));    # Wait until the wave is done
   stopClip (ego, 2);
}

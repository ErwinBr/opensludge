setCharacterOutlineThickness

Syntax:

setCharacterOutlineThickness (thisCharacter, pixels);

Purpose:

Sets how thick the outline of thisCharacter is in the OUTLINE draw mode, in pixels of the screen.

pixels goes from 0 (no outline at all) to 64. A new character has an outline of 2 pixels. The pixels are those of your game's screen, so the outline stays just as thick when the character is scaled, or when you zoom in with zoomCamera: a far-away character doesn't get a hairline, and a close-up doesn't get a thick black border.

The outline follows the shape of the character's sprite, round its corners and in between its legs, and is drawn under the character, so it only shows outside it. The z-buffer hides it where it hides the character.

Return value:

No return value.

Example:

objectType key ("key") {
}

# Called when the mouse moves over the key, and away again.
sub pointAtKey (over) {
   if (over) {
      setCharacterOutlineThickness (key, 2);
      setCharacterDrawMode (key, OUTLINE);
   } else {
      setCharacterDrawMode (key, NORMAL);
   }
}

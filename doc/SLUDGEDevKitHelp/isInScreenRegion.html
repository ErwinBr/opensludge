isInScreenRegion

Syntax:

isInScreenRegion (thisCharacter, thisObject);

Purpose:

Tests whether the hotspot of thisCharacter (the point where it stands) is inside a screen region of thisObject right now.

It works for any region, rectangle or shape, whether or not watchScreenRegion is watching it. If thisObject has more than one region, being inside any of them is enough.

Return value:

TRUE if the character is inside, and FALSE if it isn't, or if either the character or the region isn't on the screen at all.

Example:

objectType ego ("ego") {
}

objectType puddle ("puddle") {
}

sub lookAtShoes () {
   if (isInScreenRegion (ego, puddle)) say (ego, "Wet. Lovely.");
   else say (ego, "Dry, for now.");
}

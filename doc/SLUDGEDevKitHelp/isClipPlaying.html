isClipPlaying

Syntax:

isClipPlaying (character, layer);

Purpose:

Tells whether character plays an animation on layer that hasn't finished. A clip that doesn't loop finishes at its end; clips that loop, and animations of anim, never do.

Characters have one layer for now: 0. 

animate (ego, wave);
while (isClipPlaying (ego, 0)) pause (1);

Return value:

TRUE or FALSE.

isClipPlaying

Syntax:

isClipPlaying (character, layer);

Purpose:

Checks whether character is playing something on layer that hasn't finished yet.

Careful: a looping clip never finishes, and neither does an animation of anim. So if you wait in a loop like the one in the example for a looping clip or an anim on layer 0, you'll be waiting forever!

A clip that doesn't loop has finished once it gets to its end, and a clip of length 0 has finished straight away. On layers 1 to 99, a finished clip still holds its last pose until you take it away with stopClip, even though isClipPlaying says FALSE.

Return value:

Returns TRUE if the clip is still playing, otherwise FALSE.

Example:

objectType ego ("Ego") {
}

sub waveAndWait () {
   animate (ego, loadClip ('ego/wave.clp'));
   while (isClipPlaying (ego, 0)) pause (1);
}

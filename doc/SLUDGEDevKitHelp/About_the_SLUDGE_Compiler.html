About the SLUDGE Compiler

To compile a SLUDGE project, open it in the SLUDGE Dev Kit and choose Compile in the Project menu (Ctrl+B, or Command+B on macOS). The Build panel shows the progress of the compiler, and the errors and warnings that it finds in your project. Double-click one to open its script at its line.

The compiler is also a program of its own, sludge-compiler, which comes with the Dev Kit and runs without a window, for example in a terminal or in a script that builds your game:

sludge-compiler projectfile

It writes the game next to the project file. sludge-compiler --help lists its options.

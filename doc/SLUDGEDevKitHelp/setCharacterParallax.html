setCharacterParallax

Syntax:

setCharacterParallax (thisCharacter, scrollSpeedX, scrollSpeedY);

Purpose:

Makes thisCharacter move across the screen faster or slower than the scene as the camera scrolls, as a parallax layer does, so that it looks nearer to or further from the camera.

parallaxAdd is great for scenery behind the room, but things in front of the room, such as a tree trunk or a pillar that the camera pans past, are usually characters. Things close to the camera should whizz past faster than the room does, and that's what this function is for.

scrollSpeedX and scrollSpeedY are percentages of the camera's speed, as they are for parallaxAdd. 100 is a normal character. With 150, the character moves 3 pixels on the screen for every 2 that the scene moves, so it looks closer to the camera. With 50, it moves 1 pixel for every 2, so it looks further away. With 0, it stays in the middle of the screen, however the camera moves.

The character is always where you put it when the camera is centred on that spot. As the camera moves away, the character drifts away from it, faster or slower according to its scroll speeds, and comes back as the camera returns. That way, the position you give addCharacter still means something, and a character that you place in the room editor is in the right place when the camera looks at it. Say a tree is at 1200, 400, with a scroll speed of 150. When the camera is centred on 1200, 400, the tree is in the middle of the screen. Move the camera 200 pixels to the right, and the tree moves 300 pixels to the left.

Only where the character is drawn changes. Its speech, the mouse and the gamepad all go by where it's drawn, but it still walks, scales, sorts and goes behind the z-buffer by where it really is, which is also what getCharacterX and getCharacterY tell you. The light map lights it from where it really is too. A character that's FIXTOSCREEN (see setCharacterExtra) stays put on the screen and ignores its scroll speeds. pasteCharacter pastes the character where it really is, not where it's drawn.

Things that close to the camera are usually in front of everything, so you'll often want FRONT and NOZBUFFER too. To make the character normal again, set both speeds back to 100. Freezing the scene and saving the game both keep the scroll speeds.

If thisCharacter is an object type which is not currently represented on the screen as a character, the code has no effect.

Return value:

TRUE if thisCharacter is an object type which is currently represented on the screen as a character, otherwise FALSE.

Example:

objectType tree ("tree") {
}

sub forest () {
   addOverlay ('forest.tga', 0, 0);
   parallaxAdd ('hills.tga', 50, 100);

   # A tree trunk close to the camera, which whizzes past
   # faster than the room
   addCharacter (tree, 1200, 480, anim ('tree.duc', 0));
   setCharacterExtra (tree, FRONT + NOZBUFFER);
   setCharacterParallax (tree, 150, 100);
}

clipFrames

Syntax:

clipFrames (clip, part, animation);

Purpose:

Allows you to use a standard animation defined in anim as an animation clip. A legacy SLUDGE anim uses a shorter notation to display frames and run events (sound and function calls) from a single spriteBank.

The anim repeats until the clip ends: a 10-tick clip plays a 5-tick anim twice. clipFrames replaces any sprite keys the part already had in this clip. Unlike in anim, its sounds and functions fire even when the character is hidden. 

var quack = newClip (10, TRUE);							# This clip loops two passes of 5 ticks
clipFrames (quack, "", anim ('duck.duc', 0, quackSound, 1, 2, wait (3, 2))); 	# This anim takes 5 ticks to run

Return value:

None.

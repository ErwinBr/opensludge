clipFrames

Syntax:

clipFrames (clip, part, animation);

Purpose:

Turns an animation of anim into the sprites and events of part in clip.

If you already have animations made with anim, there's no need to type them all in again as sprite keys: hand them to clipFrames, and they become part of a clip. The anim repeats until the clip ends, so a clip of 10 ticks plays an anim of 5 ticks twice. clipFrames replaces any sprite keys that the part already had in this clip.

The sounds and functions of the anim become events of the clip. Unlike in anim, they happen even while the character is hidden, so a hidden character can still be heard. An anim with no frames stops the game with an error, and so does a clip that's already in use.

Return value:

No return value.

Example:

sub quack () {
   var c = newClip (10, TRUE);                               # Plays the anim twice...
   clipFrames (c, "", anim ('duck.duc', 0, 1, 2, wait (3, 2))); # ...which takes 5 ticks
   return c;
}

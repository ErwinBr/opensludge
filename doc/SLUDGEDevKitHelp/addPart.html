addPart

Syntax:

addPart (rig, name, parent, x, y);
addPart (rig, name, parent, x, y, spriteBank, sprite);

Purpose:

Adds a part called name to rig, hanging from the part called parent, and showing sprite from spriteBank.

Use "" as the parent to hang the part from the character itself. The values x and y say where the part's hotspot goes, measured from its parent's hotspot (or from its pivot, if you give it one with setPartPivot). When the parent moves, turns or scales, the part goes with it, just as a hand goes wherever the arm takes it.

spriteBank is a sprite bank file, in single quotes as always, such as 'head.duc'. The part shows that sprite until a clip gives it another one. A negative sprite shows the mirror image of that sprite.

Leave out the sprite bank and the sprite, and the part is an empty joint: it shows nothing, but the parts hanging from it go where it goes, and a clip on a layer can give it a sprite later. That's handy for whatever a character holds in its hand (see the example).

Every part needs a name of its own, and its parent has to be in the rig already, otherwise there's nothing to hang it from. Get either of these wrong and the game stops with an error. You can't add parts to a rig once a character uses it, so build the whole rig before you call setCharacterRig.

Return value:

No return value.

Example:

objectType ego ("Ego") {
}

sub holdSomething (bank, sprite) {
   var c = newClip (1, TRUE);
   clipSprite (c, "hand", 0, bank, sprite);
   return c;
}

sub init () {
   var r = newRig ();
   addPart (r, "torso", "", 0, -150, 'torso.duc', 0);
   addPart (r, "arm", "torso", 40, -60, 'arm.duc', 0);
   addPart (r, "hand", "arm", 0, 80);                     # An empty joint
   addCharacter (ego, 320, 400, anim ('torso.duc', 0));
   setCharacterRig (ego, r);

   playClip (ego, 4, holdSomething ('items.duc', 2));    # Ego holds item 2...
   pause (50);
   stopClip (ego, 4);                                    # ...and now his hand is empty again
}

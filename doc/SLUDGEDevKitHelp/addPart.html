addPart

Syntax:

addPart (rig, name, parent, x, y);
addPart (rig, name, parent, x, y, spriteBank, sprite);

Purpose:

Adds a part called name to rig, attached to the part called parent ("" for the character itself), with its origin (its sprite's hotspot) at x, y from its parent's origin. The part shows sprite of spriteBank until a clip gives it another; a negative sprite shows its mirror image.

name must be new in this rig, and parent must be added before it (or be ""). You can't add parts once a character uses the rig, which happens as soon as you give it to a character with setCharacterRig.

Without a sprite, the part is an empty joint: it shows nothing, but you can later play a clip on a layer that gives it a sprite. This way you can dynamically put items in a character's hand, for example. 

addPart (r, "head", "torso", 3, -213, 'head.duc', 0);	# Head is added as a child of torso
addPart (r, "hand", "arm", -30, 222);	# An empty joint

sub holdSomething (file, sprite) {
	var c = newClip (1, TRUE);
	clipSprite (c, "hand", 0, file, sprite);
	return c;
}

playClip (ego, 4, holdSomething ('items.duc', 2));	# ego holds item 2
stopClip (ego, 4);								# empty hand again

Return value:

None.

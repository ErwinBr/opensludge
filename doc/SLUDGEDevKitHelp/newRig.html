newRig

Syntax:

newRig ();

Purpose:

Creates a new, empty rig: the list of parts that a Composite Character is made of.

A new rig has just one part, called "" - the character itself, which all the other parts hang from. Add the head, arms, legs and so on with addPart, and then give the rig to a character with setCharacterRig.

If you made your rig in the Character Creator, you don't need this: loadRig gives you the whole rig in one go.

Return value:

Returns the new rig.

Example:

objectType ego ("Ego") {
}

sub egoRig () {
   var r = newRig ();
   addPart (r, "legs", "", -4, -1, 'legs.duc', 0);       # Hangs from the character itself
   addPart (r, "torso", "", -3, -258, 'torso.duc', 0);
   addPart (r, "head", "torso", 3, -213, 'head.duc', 0); # Hangs from the torso
   addPart (r, "arm", "torso", -79, -153, 'arm.duc', 0);
   addPart (r, "hand", "arm", -30, 222);                  # A joint, with no sprite
   return r;
}

sub init () {
   addCharacter (ego, 320, 400, anim ('legs.duc', 0));
   setCharacterRig (ego, egoRig ());
}

newRig

Syntax:

newRig ();

Purpose:

Creates a new rig, which holds the parts of a Composite Character. It has one part to begin with, its root, called "": the character itself. The root part is just an empty node in the hierarchy until you add parts with addPart. Give the rig to a character with setCharacterRig. 

sub egoRig () {
	var r = newRig ();
	addPart (r, "legs", "", -4, -1, 'legs.duc', 0);		# This part is a child of "", meaning the root of the rig
	addPart (r, "torso", "", -3, -258, 'torso.duc', 0);
	addPart (r, "head", "torso", 3, -213, 'head.duc', 0);	# This part is a child of the torso
	addPart (r, "eyes", "head", 0, 0, 'head.duc', 6);
	addPart (r, "arm1", "torso", -79, -153, 'arm1.duc', 0);
	addPart (r, "hand1", "arm1", -30, 222);          	# an empty joint: we can play a clip on it that represents an object it holds in its hand.
	addPart (r, "arm2", "torso", 70, -159, 'arm2.duc', 0);
	addPart (r, "hand2", "arm2", -9, 213);
	return r;
}

setCharacterRig (ego, egoRig ());

Return value:

The new rig.

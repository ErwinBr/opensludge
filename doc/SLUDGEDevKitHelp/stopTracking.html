stopTracking

Syntax:

stopTracking ();

Purpose:

Stops the camera following the character given to trackCharacter.

If the camera is moving, it slows down with the ease-out set by setCameraSpeed rather than stopping dead, and comes to rest on a whole pixel. Then it stays there, wherever the character goes.

Return value:

No return value.

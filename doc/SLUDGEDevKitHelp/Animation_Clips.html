Animation Clips

An animation made with anim is a list of frames from a spriteBank, shown successively during each screen update or with a given delay. A clip, made with newClip, is an animation of another kind: It has a given length, defined in screen updates ("ticks"), and keys at points in time. It gives you more features and more control than anim.

You can make clips in a script, with the functions below, or in the Animation Editor of the Dev Kit, which saves them as .clp files. Your script loads those with loadClip, and then uses them as any other clip: 

animate (ego, loadClip ('ego/wave.clp'));

clipSprite displays a sprite of a spriteBank from the given frame number at the given tick, clipEvent plays a sound or starts a function at a tick, clipFrames turns a series of frames and events (defined by anim) into a clip with keys, clipKey allows you to move, turn, scale, flip, hide and order the drawing of a clip, and mirrorClip will mirror the contents of a clip horizontally. 

sub walkClip () {
	var c = newClip (16, TRUE);	# 16 ticks, looping
	clipSprite (c, "", 0, 'ego.duc', 0);	# Tick 0, sprite 0
	clipSprite (c, "", 4, 'ego.duc', 1);	# Tick 4, sprite 1
	clipSprite (c, "", 8, 'ego.duc', 2);	# etc...
	clipSprite (c, "", 12, 'ego.duc', 3);
	clipEvent (c, 0, footstep);				# Calls a footstep function at tick 0
	clipEvent (c, 8, footstep);				# ...and again at 8
	return c;
}

Anything that takes an animation also takes a clip: animate, costume, addCharacter, setCursor and pasteImage. 

sub heroCostume () {							
	return costume (
		stand (SOUTH), stand (WEST), stand (NORTH), stand (EAST),
		walk (SOUTH), mirrorClip (walk (EAST)), walk (NORTH), walk (EAST),
		talk (SOUTH), talk (WEST), talk (NORTH), talk (EAST));
}

Time

Keys can be created at 0 and until the end of the clip. You'll get an error if you define a key outside of the length of the clip.

A looping clip will jump over the last tick and land straight on 0 again. For interpolated properties you can (and should) still assign a key at the last tick, so that these can ease towards its defined values (first and last frames of a looping animation are usually exactly the same). Clips that play once do hit the last tick, so you can safely set a key there. The character will hold it until set by something else. Each tick (screen update) of the game, a clip updates where it is and then moves to the next, at the speed of setClipSpeed. To test whether a clip is playing, you use isClipPlaying. 

sub swingBody () {
	var c = newClip (48, TRUE);			# 48 ticks, looping
	clipKey (c, "torso", PART_ROTATION, 0, 2, EASE_INOUT);	# Rotation starts at 2 degrees...
	clipKey (c, "torso", PART_ROTATION, 24, -2, EASE_INOUT);	# ...eases to -2 degrees at tick 24...
	clipKey (c, "torso", PART_ROTATION, 48, 2);   	# This closing key won't be hit (it jumps to 0), but from tick 24 the animation eases towards it.
	return c;
}

Events

With clipEvent you can run functions or play sounds at the given ticks. A clip fires its events whether its character is shown or not, contrary to anim, which doesn't fire when a character is hidden.

You can put an event anywhere from tick 0 to the last tick of the clip. An event at tick 0 happens when the clip starts. In a looping clip, it also happens each time the clip starts over. An event at the last tick happens when the clip reaches its end. In a looping clip, that is at the end of every round.

Animating Composite Characters on Layers

As of SLUDGE 2.3 we have Composite Characters that are built up from separate parts. Animation clips can animate the parts either all together, as a costume, or one by one, on layers. You give a layer number (1-99) and a clip to playClip, and the keys of that clip will either override those of the layers below, or add to them. Additive is only possible with properties that can be interpolated, such as position, rotation and scale. This opens up possibilities like eyes that blink regardless of what other animations on a character are doing at the same time. 

sub reachClip () {
	var c = newClip (48);
	clipSprite (c, "legs", 0, 'legs.duc', 0);
	clipSprite (c, "torso", 0, 'torso.duc', 0);
	clipSprite (c, "head", 0, 'head.duc', 0);
	clipSprite (c, "eyes", 0, 'head.duc', 6);
	clipSprite (c, "arm_left", 0, 'arm1.duc', 0);
	clipSprite (c, "arm_right", 0, 'arm2.duc', 0);    
	
	clipKey (c, "arm_right", PART_ROTATION, 0, 0, EASE_INOUT);
	clipKey (c, "arm_right", PART_ROTATION, 16, -80);
	clipKey (c, "arm_right", PART_ROTATION, 32, -80, EASE_INOUT);
	clipKey (c, "arm_right", PART_ROTATION, 48, 0);
	return c;
}

sub waveArm () {
	var c = newClip (72);
	clipKey (c, "arm_right", PART_ROTATION, 0, 0, EASE_INOUT);
	clipKey (c, "arm_right", PART_ROTATION, 24, -150, EASE_INOUT);
	clipKey (c, "arm_right", PART_ROTATION, 72, 0);
	return c;
}

sub showDifferences () {
	addCharacter (ego, 320, 420, egoCostume ());
	setCharacterRig (ego, egoRig ());
	turnCharacter (ego, EAST);

	# 1. This animates the character and all its parts:
	pause (animate (ego, reachClip ()));

	# 2. This animates only the arm: the other parts display their rest pose (defined with addPart).
	pause (animate (ego, waveArm ()));

	# 3. This animation is layered:
	playClip (ego, 2, waveArm ());			# on layer 2, the arm overrides whatever is set by other layers below
	moveCharacter (ego, 200, 420);			# walks west: the arm waves once, then holds still until stopClip
	stopClip (ego, 2);				# the layer, and its rotation, go
}

Animation Clips

You probably know anim already: a list of frames from a sprite bank, shown one after the other. That's fine for flicking through a few drawings, but what if you want an arm to swing smoothly, a head to bob, or a character to blink while it does something else? That's what clips are for.

A clip, made with newClip, has a length in ticks (screen updates), and keys at points in that time: at tick 0 the arm points down, at tick 12 it points forward, and SLUDGE works out everything in between. Clips can also show sprites, play sounds and call functions, just as anims can.

Making clips:

The easiest way to make a clip is in the Animation Editor of the Dev Kit, where you can see the character move while you work. It saves the clip as a .clp file, and your script loads it with loadClip: 

sub wave () {
   animate (ego, loadClip ('ego/wave.clp'));
}

You can also build a clip in a script, with these functions:

  • clipSprite shows a sprite from a given tick.
  • clipKey moves, turns, scales, flips, hides, colours or reorders a part.
  • clipEvent plays a sound or calls a function at a tick.
  • clipFrames turns an anim you already have into the sprites and events of a clip.
  • mirrorClip makes a mirror image of a clip, so a character can walk west with its walk to the east.

sub footstep () {
   playSound ('step.wav');
}

sub walkClip () {
   var c = newClip (16, TRUE);              # 16 ticks, looping
   clipSprite (c, "", 0, 'ego.duc', 0);     # Tick 0, sprite 0
   clipSprite (c, "", 4, 'ego.duc', 1);     # Tick 4, sprite 1
   clipSprite (c, "", 8, 'ego.duc', 2);     # And so on...
   clipSprite (c, "", 12, 'ego.duc', 3);
   clipEvent (c, 0, footstep);              # A footstep at tick 0...
   clipEvent (c, 8, footstep);              # ...and another at tick 8
   return c;
}

Anything that takes an animation takes a clip too: animate, costume, addCharacter, setCursor and pasteImage. Add all the keys and events of a clip before you use it, though: once it's in use, it can't change.

Time:

Keys go anywhere from tick 0 to the end of the clip. A key outside the clip gives you an error.

A looping clip jumps straight from the tick before the last back to tick 0, without showing the last tick. That's because the first and last frames of a loop are usually exactly the same, and showing both would make the loop stutter. Do still put a key at the last tick, though: the movement before it eases towards that key, even if it's never shown. A clip that plays once does get to its last tick, and the character holds that pose until something else moves it.

Every tick of the game, a clip moves on one step, at the speed that setClipSpeed gives it. To find out whether a clip has finished, use isClipPlaying. 

sub swingBody () {
   var c = newClip (48, TRUE);                                 # 48 ticks, looping
   clipKey (c, "torso", PART_ROTATION, 0, 2, EASE_INOUT);     # Start leaning 2 degrees...
   clipKey (c, "torso", PART_ROTATION, 24, -2, EASE_INOUT);   # ...ease over to -2...
   clipKey (c, "torso", PART_ROTATION, 48, 2);                # ...and back again to where it started
   return c;
}

Events:

With clipEvent, a clip plays sounds or calls functions at the ticks you choose. Unlike the sounds and functions of an anim, they happen whether the character is shown or not.

An event at tick 0 happens when the clip starts, and an event at the last tick when the clip gets to its end. In a looping clip, they happen again in every round.

Clips on layers:

Clips really come into their own with Composite Characters, which are made of separate parts. A clip can move all the parts together, as a costume does, or just a few of them, on a layer of its own. Give playClip a layer number from 1 to 99 and a clip, and the keys of that clip either replace what the layers below say, or add to it. Only things that have values in between can be added to, such as positions, angles, sizes and colours. That's how a character can blink, whatever else it happens to be doing. 

objectType ego ("Ego") {
}

sub reachClip () {
   var c = newClip (48);
   clipKey (c, "arm", PART_ROTATION, 0, 0, EASE_INOUT);
   clipKey (c, "arm", PART_ROTATION, 16, -80);
   clipKey (c, "arm", PART_ROTATION, 32, -80, EASE_INOUT);
   clipKey (c, "arm", PART_ROTATION, 48, 0);
   clipKey (c, "torso", PART_ROTATION, 0, 0, EASE_INOUT);
   clipKey (c, "torso", PART_ROTATION, 24, 10, EASE_INOUT);
   clipKey (c, "torso", PART_ROTATION, 48, 0);
   return c;
}

sub waveArm () {
   var c = newClip (72);
   clipKey (c, "arm", PART_ROTATION, 0, 0, EASE_INOUT);
   clipKey (c, "arm", PART_ROTATION, 24, -150, EASE_INOUT);
   clipKey (c, "arm", PART_ROTATION, 72, 0);
   return c;
}

sub showTheDifference () {
   addCharacter (ego, 320, 420, loadClip ('ego/stand.clp'));
   setCharacterRig (ego, loadRig ('ego/ego.rig'));

   # 1. The whole character reaches: the torso leans and the arm goes up
   pause (animate (ego, reachClip ()));

   # 2. Only the arm waves: the other parts stand as they do in the rig
   pause (animate (ego, waveArm ()));

   # 3. On a layer, the arm waves on top of whatever else is going on
   playClip (ego, 2, waveArm ());
   moveCharacter (ego, 200, 420);     # Walks west, waving, then holds the arm still...
   stopClip (ego, 2);                 # ...until the layer goes
}

Object Types as Screen Regions

Once an object type has been defined it can be represented by a region of the screen. Screen regions do not need to be defined in order for the background image to animate - this can be achieved through repeated calls to the addOverlay command. Rather, screen regions are used purely to enable a user's interaction with buttons on their screen, or with items in a scene in a game.

A screen region can be a simple rectangle, or a shape of your own given as a list of points, which fits round an object much better than a box can. Use showBoxes while you're working on a scene to see where the regions are.

Regions aren't only for the mouse. With watchScreenRegion, a function runs whenever a character walks into a region or out of it: handy for doorways, puddles and trapdoors. isInScreenRegion tells you whether a character is standing in one right now.

Functions for working with a specific screen region:

addScreenRegion

isInScreenRegion

isScreenRegion

removeScreenRegion

watchScreenRegion

watchScreenRegion

Syntax:

watchScreenRegion (thisObject, onEnter, onLeave);

Purpose:

Watches the screen regions of thisObject, so that the function onEnter runs whenever a character steps into one of them, and the function onLeave whenever a character steps out again.

What counts is the character's hotspot: the point where it stands, which is the position you give to addCharacter or jumpCharacter. It doesn't matter how the character gets there. Walking, jumping or being forced all count, and so does a character that's hidden at the time.

Both functions must take two parameters: first the character that went in or out, then the object of the region. So the function can tell who it was, and one function can look after lots of regions at once. If two characters step in at the same time, the function runs twice, once for each of them. If a character steps straight from one watched region into another, the onLeave of the first runs before the onEnter of the second. A function with a different number of parameters stops the game with an error as soon as it's called.

Either function can be NULL if you only care about one of the two. Call watchScreenRegion again for the same object to change its functions, and use NULL for both to stop watching it.

The watch belongs to the object rather than to one region, so it covers every region of thisObject and carries on after removeScreenRegion. Add the region again, in another room say, and the watch works again. Anything that changes whether a character is inside counts, not just walking: a watch that starts with a character already inside runs onEnter, and removing the region, or the character, while it's inside runs onLeave. Freezing the game (see freeze) puts the watches away with the rest of the scene, and unfreezing brings them back without running anything. Saved games keep them too.

Return value:

No return value.

Example:

objectType ego ("ego") {
}

objectType dog ("dog") {
}

objectType doormat ("doormat") {
}

sub stepOnMat (who, where) {
   if (who == ego) say (ego, "Welcome home, me.");
   else if (who == dog) say (dog, "Woof!");
}

sub setUpHall () {
   addScreenRegion (doormat, newStack (200, 380, 300, 380, 320, 420, 180, 420), 0, 0, -1);
   watchScreenRegion (doormat, stepOnMat, NULL);
}

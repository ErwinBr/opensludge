loadRig

Syntax:

loadRig (rigFile);

Purpose:

Loads a rig that you made in the Character Creator, so you don't have to build it part by part with addPart.

rigFile is a .rig file of your project, in single quotes, just like a sprite bank or a sound. You get exactly the same thing as a rig built with newRig: all the parts, with their sprites, their pivots and the pose they stand in. Give it to a character with setCharacterRig. Until you do, you can still add parts to it, or change their pivots or depths.

The compiler puts the rig into your game, together with the sprite banks it uses. If one of those banks is missing, the compiler tells you which one, and in which script and on which line you load the rig, so you don't find out halfway through the game. Give it anything other than a rig, such as a .clp file, and the game stops with an error. The clips you made for the rig in the Animation Editor load with loadClip.

Return value:

Returns the rig, ready for setCharacterRig.

Example:

objectType ego ("Ego") {
}

sub init () {
   addCharacter (ego, 320, 400, anim ('ego.duc', 0));
   setCharacterRig (ego, loadRig ('ego/ego.rig'));    # The parts from the Character Creator
}

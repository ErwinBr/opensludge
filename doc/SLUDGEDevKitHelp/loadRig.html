loadRig

Syntax:

loadRig ('rigFile');

Purpose:

Loads a rig that you made in the Character Creator of the Dev Kit: a .rig file of your project, with all its parts, their sprites, their rest pose and their pivots. You get the same rig as one you build with newRig and addPart, so you give it to a character with setCharacterRig. Until a character uses it, you can still add parts to it, or change their depth or pivot.

Name the file in single quotes, as you name sprite banks and sounds, from the folder of your project. The compiler puts the rig into your game, together with the sprite banks that it uses. If one of those banks is missing, the compiler tells you which one, and in which script and line you load the rig.

loadClip loads the clips that you made for the rig in the Animation Editor. 

objectType ego ("Ego") {
}

sub init () {
	addCharacter (ego, 320, 400, egoCostume ());
	setCharacterRig (ego, loadRig ('ego/ego.rig'));	# The parts of the Character Creator
}

Return value:

The rig.

peekStart and peekEnd

Syntax:

peekStart (thisStack);

peekEnd (thisStack);

Purpose:

Looks at the element at one end of thisStack without taking it off: peekStart at the first, and peekEnd at the last.

peekStart looks at the first element, the one that popFromStack and dequeue would remove and that pushToStack adds. peekEnd looks at the last element, the one that enqueue adds. The stack itself stays as it was.

The stack mustn't be empty, or the game stops with an error! If you're not sure, check it first: a stack counts as FALSE when it's empty.

Return value:

peekStart returns the value of thisStack[0], and peekEnd returns the value of the last element.

Example:

objectType ego ("Ego") {
}

sub init () {
   var queue = newStack ("Bert", "Ernie", "Kevin");
   if (queue) {
      say (ego, peekStart (queue) + " is first, and " + peekEnd (queue) + " is last.");
   }
}

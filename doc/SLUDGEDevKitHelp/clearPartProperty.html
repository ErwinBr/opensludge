clearPartProperty

Syntax:

clearPartProperty (character, part, property);

Purpose:

Hands the property of part of character back to the character's clips, after setPartProperty took it over.

The part goes back to whatever its clips say at that moment. If the property wasn't set in the first place, nothing happens, and that's not an error either.

Return value:

Returns TRUE if there is such a character, otherwise FALSE.

Example:

objectType ego ("Ego") {
}

sub stopFollowingTheMouse () {
   clearPartProperty (ego, "head", PART_ROTATION);
}

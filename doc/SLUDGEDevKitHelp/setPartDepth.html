setPartDepth

Syntax:

setPartDepth (rig, name, depth);

Purpose:

Sets which parts of a character the part called name is drawn in front of, and which it's drawn behind.

Parts with a lower depth are drawn first, so they end up behind the others. Parts of the same depth are drawn in the order you added them. Every part starts at 0, so giving the far arm a depth of -1 puts it behind the body.

This is where the part sits normally. A clip can still move it for a while with PART_DEPTH (see clipKey), which is handy for bringing the far arm forward when the character turns round. Depth only sorts out the parts of one character: where the character stands among other characters and the scenery still depends on where it is on the screen, as always.

Call it while you build the rig, before you give the rig to a character with setCharacterRig, because after that the rig can't change. A name that isn't a part of the rig stops the game with an error. In the Character Creator, this is the Depth of a part in the Inspector.

Return value:

No return value.

Example:

sub armRig () {
   var r = newRig ();
   addPart (r, "torso", "", 0, -150, 'torso.duc', 0);
   addPart (r, "farArm", "torso", 30, -90, 'arm.duc', 0);
   setPartDepth (r, "farArm", -1);          # Draw the far arm behind the torso
   return r;
}

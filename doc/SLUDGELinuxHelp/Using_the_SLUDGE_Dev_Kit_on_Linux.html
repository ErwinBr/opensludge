Using the SLUDGE Dev Kit on Linux

Once installed, the SLUDGE Dev Kit is in the menu of your desktop, under Development, and it opens the files of SLUDGE projects when you double-click them. You can also start it with

sludge-devkit

followed by the files to open, if any. The compiler and the engine, which the Dev Kit runs, are sludge-compiler and sludge-engine.

Further documentation about the Dev Kit can be found in the SLUDGE Dev Kit Help.

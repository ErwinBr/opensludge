Syntax highlighting for gedit

Syntax highlighting for SLUDGE scripts in the text editors that use GtkSourceView, such as GNOME Text Editor and gedit, is installed automatically during the installation of the SLUDGE Dev Kit.

To install it manually, copy packaging/linux/sludge.lang from the source of SLUDGE to ~/.local/share/gtksourceview-5/language-specs (for GNOME Text Editor) or ~/.local/share/gtksourceview-4/language-specs (for gedit).
